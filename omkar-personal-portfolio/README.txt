RUN LOCALLY ON WINDOWS
1. Extract omkar-personal-portfolio.zip to a folder.
2. Open the folder in VS Code (File > Open Folder).
3. Double-click index.html in File Explorer to preview in Chrome.
4. Edit HTML/CSS in VS Code, save, then refresh Chrome.

PERSONALIZE BEFORE PUBLISHING
1. Confirm the email, WhatsApp number and Instagram profile are current.
2. Replace the abstract sample project artwork and descriptions with your own edits.
3. Add direct URLs for your showreel and individual work samples.
4. Update about.html with accurate experience, location and skills.
5. Test every page and link on desktop and mobile.

FREE HOSTING WITH GITHUB PAGES
1. Create a GitHub account if needed.
2. Create a NEW public repository, e.g. omkar-personal-portfolio.
3. Upload all files and folders from the extracted project. Keep index.html in the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for the Pages deployment to finish. Your site will be available at the URL shown in Settings > Pages.
